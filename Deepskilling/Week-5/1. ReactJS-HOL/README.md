# ReactJS Hands-on Lab 1

This project is a simple React application created using **Create React App** as part of the **ReactJS Hands-on Lab 1** exercise.

The application displays the following heading on the home page:

> **Welcome to the First Session of React**

## Features

* Built with **Create React App**
* Displays a welcome message using a React component
* Simple and clean UI with centered content
* Basic CSS styling for layout and spacing

## Project Structure

* **`src/App.js`** – Contains the main React component that renders the welcome message.
* **`src/App.css`** – Provides styling for the page layout and text alignment.

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```

## Build the Project

Create an optimized production build:

```bash
npm run build
```

## Run Tests

Execute the test suite:

```bash
npm test -- --watchAll=false
```
