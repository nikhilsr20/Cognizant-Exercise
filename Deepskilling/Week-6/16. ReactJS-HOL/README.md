# ReactJS Hands-on Lab 16

This project implements **ReactJS Hands-on Lab 16** by creating a registration form with basic form validation.

## Project

* **Project Name:** `mailregisterapp`

## Implementation

* Created a `Register` component.
* Designed a registration form with:

  * Name
  * Email
  * Password
* Added validations:

  * Name must contain at least 5 characters.
  * Email must be in a valid format.
  * Password must contain at least 8 characters.
* Implemented validation using form input and submit event handlers.

## Run the Project

```bash
npm install
npm start
```
