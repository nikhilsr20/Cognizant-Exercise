# ReactJS Hands-on Lab 17

This project implements **ReactJS Hands-on Lab 17** by fetching and displaying user details from the Random User API.

## Project

* **Project Name:** `fetchuserapp`

## Implementation

* Created the `Getuser` functional component.
* Used `useEffect()` to fetch user data from the Random User API.
* Managed user and loading state using `useState()`.
* Displayed the user's title, first name, and profile image.

## Run the Project

```bash
npm install
npm start
```
